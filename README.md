## 🚀 Featured Projects

### 1. 📩 Spam Message Classifier (NLP)
**An NLP text classifier engineered for high precision, so legitimate messages are never marked as spam.**
- Full **text preprocessing pipeline**: lowercasing, regex tokenization, stop-word removal, and **TF-IDF / Count** vectorization.
- Compared **Multinomial Naive Bayes vs Logistic Regression**, with a decision threshold tuned for ≥ 99% precision.
- Rigorous evaluation on a **held-out test set with no data leakage**: **100% precision, 94.4% F1, 98.6% accuracy** and **0 false positives**.
- Includes confusion matrices, a saved **joblib** pipeline, and a **real-time interactive prediction** function.

`Python` `Scikit-learn` `NLP` `TF-IDF` `Pandas` `Matplotlib` `Seaborn`
[**View Repository →**](https://github.com/Maria-Chaudhary/spam-classifier)

### 2. 🎙️ Voice-to-Voice AI Assistant
**An interactive voice chatbot you can talk to, in English and Urdu.**

- Supports **English and Urdu** conversations through a **Gradio** interface.
- Deployed on **Hugging Face Spaces**.

`Python` `Whisper` `Groq` `LLaMA` `gTTS` `Gradio` `Hugging Face Spaces`
[**View Repository →**](https://github.com/Maria-Chaudhary/voice-to-voice-ai-assistant)
